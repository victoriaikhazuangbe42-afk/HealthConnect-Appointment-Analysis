# HealthConnect Clinic – Week 8

## Final Analytics and Decision Support

This project focused on completing the HealthConnect Clinic appointment analysis and refining the Power BI dashboard to support better decision-making.

### What I Did
- Analysed appointment data to identify patterns associated with missed appointments.
- Investigated booking lead time and previous no-show history.
- Evaluated KPIs, including overall no-show rate, repeat no-show rate, and lost slot rate.
- Refined the Power BI dashboard by adding interactive slicers and improving its layout.
- Tested and corrected the dashboard's DAX measure and distance category sorting.
- Developed recommendations based on the findings.
- Shared key findings with the Data Science track to support further analysis.

### Key Finding
Appointments booked more than 30 days in advance had a 60.5% no-show rate. Among these, appointments with a previous no-show history had a 67.9% no-show rate.

### Tools Used
Power BI, Power Query, DAX, and GitHub.

### Outcome
Completed the final analytics, dashboard refinement, testing, and decision-support documentation for Week 8.

*Note: The dataset is synthetic, and the findings show associations rather than causation.*
